This repository is the official source for Engage Pro Elite firmware releases.

- Known issues (if applicable)

---

## 🐞 Issue Tracking

This repository is also used to track **software and firmware-related issues**.

👉 [Report an Issue](../../issues)

### ✅ Report here if:
- Audio playback issues (Bluetooth or wired)
- WiFi portal problems
- Firmware update failures
- Button behaviour inconsistencies (software-related)
- Unexpected system behaviour

### ❌ Do NOT report here if:
- A cable is damaged or not working
- A button is physically broken or unresponsive
- Hardware is faulty or damaged
- You have order, delivery, or warranty queries

For those issues, please contact via:
- Etsy (order support)
- Official Engage website
- Our Social Media pages

---

## 📝 Before Reporting an Issue

Please include as much detail as possible:

- Firmware version
- Operating mode (Bluetooth or wired)
- Bluetooth speaker model (if applicable)
- Steps to reproduce the issue
- Expected behaviour
- Actual behaviour

Clear reports = faster fixes 👍
